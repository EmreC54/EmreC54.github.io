Emre API

Profilim, takım çantam, deneyimim ve yazılarım gerçek JSON uçları olarak yayında. Her biri burada belgelenmiş: dene, cevabı gör, adresi kendi koduna ya da terminaline götür.

anlatım:

Uygulamalar birbirleriyle “API” denen kapılardan konuşur: bir adres istersin, karşılığında düzenli bir bilgi (JSON) gelir. Buradaki kapılar gerçek. Bir satırı aç, Dene’ye bas, gelen cevabı gör; adresi kendi tarayıcına da yapıştırabilirsin.

OpenAPI 3.0 ile belgelenmiş, GitHub Pages’te statik JSON olarak sunulan salt okunur uçlar. Her yayında scripts/build.mjs icerik.json’dan yeniden üretir; kimlik doğrulama yok, Access-Control-Allow-Origin: *. İki sunucu: Türkçe (/api) ve İngilizce (/api/en).

Emre API 1.0.0 OAS 3.0

api/openapi.json

Emre Çuhadar’ın sitesinin salt okunur JSON uçları; her yayında icerik.json’dan üretilir. Kimlik doğrulama yok; CORS açık.

Kendi terminalinden: curl -s https://emrec54.github.io/api/emre.json
